## 🚀 Proyectos destacados

### 🛰️ [Balizas v16 MVP](https://github.com/Lideiras/Balizas-v16-MVP)
> API de seguimiento de las **balizas V16 activas**, sí, las que salieron en la tele 🤓

Proyecto en **Python** que recoge los datos de las balizas, los geolocaliza y los muestra en un **mapa interactivo** con información relevante de cada una.

- 🔎 **Scraping** de datos de balizas activas.
- 📍 **Geocodificación** para obtener la ubicación de cada baliza.
- 🗺️ **Mapa interactivo** en HTML generado automáticamente.
- ⚙️ Número de balizas a geolocalizar configurable.
